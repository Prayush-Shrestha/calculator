#  Calculator

A simple and user-friendly **Calculator Web Application** that performs basic mathematical operations through a clean and responsive interface.

##  Features

*  Addition
*  Subtraction
*  Multiplication
*  Division
*  Decimal number calculations
*  Clear/reset functionality
*  Delete/backspace functionality
*  Responsive user interface
*  Fast and easy to use

##  Technologies Used
* Python
